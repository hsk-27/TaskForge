# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

TaskForge takes security and software reliability seriously. If you discover a vulnerability or potential security flaw:

1. **Do not create a public GitHub issue.**
2. Please report the issue privately by emailing the maintainers or using GitHub Private Vulnerability Reporting.
3. Include:
   - Detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept code.
   - Potential impact on concurrent workers, database connections, or API endpoints.

We will acknowledge receipt within 48 hours and work with you to test and deploy a fix.
